# じゃんけんゲーム

ブラウザで遊べるじゃんけんゲーム。`index.html` をダブルクリックして開くだけで遊べる。

## 機能

- **モード**：フリープレイ（何回でも）／マッチ（3勝先取。勝敗が決まると「もう一試合」で再戦）
- **CPUの強さ**：
  - やさしい … ときどきCPUがわざと負けてくれる
  - ふつう … 完全ランダム
  - つよい … プレイヤーが出した手の傾向（回数）を読んで、一番多い手のカウンターを出しやすくなる
- **戦績**：勝ち／負け／あいこ／連勝／最高連勝／勝率を表示。戦績と設定は `localStorage` に保存されるので、ページを閉じても残る（「戦績をリセット」で消去）
- **対戦履歴**：直近8戦の手と結果を表示
- **キーボード操作**：`1` = グー、`2` = チョキ、`3` = パー
- 連勝が3以上になると連勝表示が盛り上がり、マッチに勝つと紙吹雪が出る
- **見た目**：背景は `images/bg.jpg`、フォントは丸くてポップな「Cherry Bomb One」（Google Fonts）。Cherry Bomb One はかな専用で漢字がないので、漢字は同じくポップな「Mochiy Pop One」にフォールバックして、漢字もかわいい書体で表示される（最終フォールバックは「M PLUS Rounded 1c」）。ネットがない環境では通常の丸ゴシックになる。タイトルなどの見出しには、紫の縁取り＋グラデーション＋落ち影で「袋文字＋凹み影」のエフェクトを CSS で付けている

## 画像・音の差し替え

下のファイル名で置くと、自動でそのファイルが使われる。
置いていないものは、絵文字（✊✌️✋）とブラウザで作った音で代わりに動く。

| 種類 | ファイル |
|---|---|
| 背景 | `images/bg.jpg` |
| グー | `images/gu.png` |
| チョキ | `images/choki.png` |
| パー | `images/pa.png` |
| BGM（ループ） | `sounds/bgm.mp3` |
| ぽん！ | `sounds/pon.mp3` |
| 勝ち | `sounds/win.mp3` |
| 負け | `sounds/lose.mp3` |
| あいこ | `sounds/draw.mp3` |

ファイル名や形式（`.jpg`、`.wav` など）を変えたいときは、`script.js` の一番上にある `HANDS` と `SOUNDS` を書き換える。

## ファイル構成

- `index.html` … 画面
- `style.css` … 見た目
- `script.js` … ゲームの動き
